# Security policy

Please do not post a security vulnerability in a public issue or PR. Use GitHub's **Report a vulnerability** action in the [Miles Tech Studios edition repository](https://github.com/milesalexg-tech/miles-tech-studios-bedrock/security/advisories/new), when enabled. Include the affected project, patch, impact, and steps to reproduce. Coordinate upstream issues through the original project's private reporting channel. The edition is independent of StackAnvil and retains its source credit and licenses.

Do not commit Bedrock account tokens, proxy certificates, traffic captures, or session logs. The development tools keep local data under ignored directories. Remove private data before attaching logs to an issue.
