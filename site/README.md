# Miles Tech Studios edition website

This Jekyll site uses the original StackAnvil documentation theme and styles, based on Just the Docs. Original project credit is in the footer and [CREDITS.md](../CREDITS.md).

```bash
cd site
bundle install
bundle exec jekyll serve
```

The configured project URL is `https://milesalexg-tech.github.io/miles-tech-studios-bedrock/`. Local serving uses the same project base path. The GitHub website workflow builds a downloadable test artifact only; Pages deployment is disabled. No domain or Search Console ownership from the original StackAnvil site is claimed.
