# Credits and provenance

Miles Tech Studios Bedrock is a separately maintained edition of [StackAnvil/patches](https://github.com/StackAnvil/patches). StackAnvil's contributors created the original patch stack, build and capture tooling, documentation, and research. Their commit history and patch authorship remain intact.

The edition builds on the work of:

- [Florian Reuth and ViaFabricPlus Bedrock contributors](https://github.com/ViaVersionAddons/viafabricplus-bedrock).
- [ViaBedrock contributors](https://github.com/ViaVersionAddons/ViaBedrock).
- [ViaFabricPlus and ViaVersion contributors](https://github.com/ViaVersion/ViaFabricPlus).
- [ViaProxy contributors](https://github.com/ViaVersion/ViaProxy).
- [CubeConverter contributors](https://github.com/oryxel1/CubeConverter).
- [Just the Docs contributors](https://github.com/just-the-docs/just-the-docs), whose theme supports the documentation site.

The repository keeps its existing [LICENSE](LICENSE). Upstream source trees and packaged components retain their own license files, copyright notices, and attribution. Edition branding does not replace those licenses or claim ownership of upstream work.

The existing artwork under `assets/publishing/` was created by the StackAnvil maintainer; it is retained as upstream material and is not presented as newly created Miles Tech Studios artwork. Historical documentation and research retain original project names and source links.

Miles Tech Studios maintains this edition and contributed the bounded resource preparation and download decoding, conversion retention limits, chunk work selection and scheduling, actor snapshot and locator caching, macOS replay portability, and edition integration recorded in [the validation notes](docs/performance-validation.md). Original patch authors remain credited in the exported patches and history.
